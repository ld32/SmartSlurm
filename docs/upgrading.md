# Upgrading

Back up your config before upgrading, then pull:

```bash
cd ~/SmartSlurm
cp ~/.smartSlurm/config/config.txt ~/.smartSlurm/config/config.txt.backup
git pull

# then re-apply any personal changes to the new config.txt manually
```
